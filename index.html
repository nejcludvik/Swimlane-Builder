Working with diagrams

Create: add shapes from the toolbar. Drag their bodies to move them. Double-click a shape, stage, lane, or connector label to edit text.

Connect: drag a blue port to another port or shape. Or choose Connect, then tap the source and destination. Connector endpoints stay on the chosen sides. Select a connector to set its label or drag the orange handles to route it manually. Reset route restores automatic obstacle avoidance.

Arrange: Shift-click shapes to select a group. Drag any selected shape to move the group. Use the inspector to resize shapes, change their lane/stage, reorder rows/columns, or align a group.

Navigate: use the zoom buttons or Ctrl/Cmd + mouse wheel. Choose Pan or hold Space and drag. On touch screens, Pan mode supports one-finger panning; select mode supports shape dragging.

Undo / Redo Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z or Ctrl+Y
Save / Open Ctrl/Cmd+S / Ctrl/Cmd+O
Duplicate / Select all Ctrl/Cmd+D / Ctrl/Cmd+A
Move selection Arrow keys; Shift = 10 pixels
Delete / Cancel Delete or Backspace / Escape
Select / Connect / Pan V / C / H

Recovery: changes are saved in this browser automatically. Save JSON to keep a portable copy. Old diagram JSON files are supported. Keep only one active editing tab to avoid overwriting its recovery copy.
